# My Personal Page

This is a fully customizable personal homepage. It is an open, free-to-change space designed to showcase a bio, favorite games, movies, and current projects using a blue aesthetic.

## Features

* **Blue Theme:** A deep, high-contrast blue color palette built for clean readability.
* **Animated Background:** A smooth, floating grid background.
* **Media Layouts:** Built-in grids and banner lists to display movies, games, or artwork.
* **Responsive:** Seamlessly switches between a two-column desktop view and a stacked mobile layout.
* **Interactive Scratchpad:** A built-in, pixel-art style drawing canvas in the sidebar. Fully configurable at ./assets/js/script.js.

## Customizing

Since this page is made to be changed, you can easily open up the files to:
1. Edit the text inside the card containers to update your bio or skills.
2. Swap the image sources in the games and gallery sections to show your own media.
3. Update the links on the buttons to route to your GitHub, socials, or other projects.
4. Modify the drawing logic or grid constraints in your JavaScript file to change how the Scratchpad behaves.
